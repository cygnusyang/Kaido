# Kairo 主窗口 UI/UX 重设计规格

- 版本：1.0
- 日期：2026-10-18
- 状态：已冻结（DM-2 / DM-3 / DM-4 / DM-5，待实施）
- 输入：用户重设计需求；竞品调研（OmniPlan 交互参考）；交互方案 1/2、2/2；视觉规格 v3；lead 裁定
- 上位依据：[DESIGN.md](../DESIGN.md)、[02-architecture.md](../02-architecture.md) ADR-013、[01-prd.md](../01-prd.md)
- 适用范围：macOS 主窗口；`KairoPresentation` 快照字段与跨平台复用边界

## 1. 目标与约束

当前主窗口把任务排成一列：大纲只有标题、状态与日期；甘特与大纲分离切换；依赖、完成度、违例与项目健康度彼此割裂。用户判定它「更像任务的罗列」。

重设计目标：让用户在同一屏同时看见**时间、任务关系与完成情况**。参考 OmniPlan 的信息密度与直接操控，按 Kairo「科技·AI·计划·自动」定位形成自己的交互。

工程约束：

1. 使用已定稿的新图标与品牌，不改图标资产。
2. UI 层与核心业务层分离。UI、CLI、MCP 共用同一套核心与命令层。
3. 架构高可复用、可扩展、支持多平台。

视觉规则见 [DESIGN.md](../DESIGN.md)。本文档描述信息架构、交互与状态，不重复色值。

术语：沿用 [04-glossary.md](../features/04-glossary.md)。本文档使用「重要路径」；「关键路径」只作同义说明。视图模式定名为「计划」与「大纲」。

## 2. 信息架构

主窗口是「计划工作台」，不是视图切换容器。

| 区域 | 内容 |
|---|---|
| 工具栏 | 视图模式、缩放、重要路径开关、违例徽标、AI 过滤徽标、保存状态、新建、检查器开关 |
| 筛选栏（32pt，可收起） | 自然语言筛选、筛选令牌、查找入口 |
| 主工作区 | 大纲列 + 时间画布 + 检查器；两级表头固定在顶部 |
| 状态栏（26pt） | 健康点、加权总进度、逾期/违例/重要路径计数、剩余天数、可见范围、缩放 |
| 检查器 | 任务页 / 项目页（无选择）/ 违例页 |

### 2.1 视图模式

| 模式 | 行为 | 快捷键 |
|---|---|---|
| 计划（默认） | 大纲与时间画布并排，逐行对齐，共享纵向滚动 | `⌥⌘1` |
| 大纲 | 全宽大纲，保留全部列与就地编辑，用于密集编辑 | `⌥⌘2` |

- 启动固定进入计划模式。模式不跨会话持久化。
- 图表聚焦（`⌥⌘L`）将左侧大纲收为 180pt 标签栏，画布占满剩余宽度；再按一次恢复。
- 在大纲模式按 `⌥⌘L`，应用进入计划模式并同时聚焦。切回大纲模式退出聚焦并恢复进入前的大纲宽度。
- 聚焦标签栏固定三列：状态 18 / 违例 18 / 标题可用 144。标题不使用 160 下限、不随字号缩放，单行截断并提供 tooltip 与全文 `accessibilityLabel`。

### 2.2 启动与持久化

- 启动：计划模式；全部群组展开；缩放取「适合项目」，无任务时取周。
- 窗口宽度 ≥ 1120 时检查器与筛选栏展开；窄窗自动收起。
- 持久化：栏宽、展开集合、缩放、窗口起点、检查器宽度与标签。
- 不持久化：视图模式、筛选条件、图表聚焦状态。

## 3. 尺寸与响应式

| 项 | 值 |
|---|---|
| 窗口默认 / 最小 | 1440×900 / 820×520 |
| 工具栏 / 筛选栏 / 状态栏 | 52（参考）/ 32 / 26 |
| 两级表头 | 44（22 + 22） |
| 行高 | 默认 28；随字号取 `max(28, bodyFontSize + 15)` |
| 大纲默认 / 范围 | 600 / 320–640 |
| 画布最小宽 | 320 |
| 检查器默认 / 范围 | 320 / 280–420 |
| 图表聚焦标签栏 | 180 |
| 缩放日宽 | 日 32 / 周 12 / 月 5 |
| 自定义日宽 | 2–120 点/天（单一标量，全轴等比：每天等宽、每周等宽）；刻度粒度按 ≥18 逐日 / ≥6 逐周 / 其余逐月由实际日宽推导 |

宽度分配顺序：

1. 检查器停靠时先占 320。
2. 画布保底 320；1pt 分隔线计入画布预算。
3. 大纲取剩余宽度，并在 320–640 内夹取用户偏好值。
4. 夹取不回写偏好；窗口变宽后恢复用户偏好。

由此 820 宽时大纲最多 500，1120 宽时最多 480，≥1240 时可保持 600。

检查器响应式：

- ≥1120：停靠。
- 820–1119：自动收起。重新打开时以 300pt 浮层覆盖画布右缘；Esc 或点击外部关闭。
- 浮层打开时临时把大纲压到 320，画布约 500。关闭后恢复用户偏好。

## 4. 大纲

### 4.1 列

| 列 | 宽 | 可编辑 |
|---|---|---|
| 状态 | 18 | 是（菜单） |
| 违例 | 18 | 否 |
| 编号 | 30 | 否 |
| 标题 | flex，最小 160 | 是 |
| 开始 | 78 | 否（排期结果） |
| 结束 | 78 | 否（排期结果） |
| 持续 | 56 | 是 |
| 负责人 | 76 | 是 |
| 完成度 | 72 | 是 |

列降级（默认字号）：≥586 全列；510–585 隐藏负责人；454–509 隐藏持续；376–453 隐藏结束；320–375 隐藏开始。状态、违例、编号、标题、完成度始终可见。大纲不做横向滚动。

字号档位 13 / 15 / 17。日期、持续、负责人、完成度列宽按 `bodyFontSize / 13` 缩放；标题最小 `160 × scale`；降级阈值按缩放后的总宽重算。编号、状态、违例列固定 11pt 与固定列宽。

### 4.2 行

- 行高 28，与画布行严格同高、同序。
- 选中、悬停、就地编辑、群组、汇总、逾期、重要路径、违例各自有独立视觉态。
- 完成度列同时显示百分比与微型进度条。`100%` 与 `done` 双向联动；`completedAt` 由命令层写入或清空。
- 群组行显示聚合开始、结束、持续与加权进度，只读，并提示「由子任务聚合」。
- 群组状态：全部子项完成 → `done`；存在 `inProgress` → `inProgress`；存在未完成 `blocked` → `blocked`；其余 `pending`。
- 空群组显示 11pt `textSecondary`「空群组」，选中行提升为 `textPrimary`，不产生违例。
- 标题单行尾部省略；悬停显示全文；VoiceOver 读取完整标题。
- 逾期：结束列变红并在标题后缀 10pt 时钟。无排期时结束列显示「—」，逾期标记落在标题后缀。
- 截止风险：计划结束晚于截止日期时显示警告图标与 tooltip。逾期与截止风险口径不同，不共用红色。
- 优先级「紧急」使用 warning 橙加「!」形状。

### 4.3 展开、筛选与拖拽

- 展开集合持久化。筛选激活时，命中任务的祖先链强制可见并展开。
- 退出筛选恢复用户原有展开状态。筛选不写入持久化视图状态。
- 聚合始终基于全量子树；过滤只影响可见性。
- 单行拖拽重排属于本期范围：显示插入线、可拖入群组、悬停自动展开、可撤销。多选拖拽不做。
- 筛选激活时禁用拖拽重排。
- 拖拽目标拒绝自身与后代。

### 4.4 键盘

| 按键 | 行为 |
|---|---|
| ↑ / ↓ | 移动选择 |
| Return | 进入就地编辑；编辑中提交 |
| `⌘↩` | 新建同级 |
| `⌘⌥N` | 新建任务 |
| `⌘⌥G` | 新建群组 |
| `⌘⌥M` | 新建里程碑 |
| Tab | 缩进 |
| `⇧Tab` | 出缩进 |
| `⌃Tab` | 将焦点移出大纲 |
| Esc | 取消编辑 |
| 双击 | 进入编辑 |
| `⌘]` / `⌘[` | 缩进 / 出缩进（沿用现有命令） |

`⌃Tab` 必须保留，全键盘访问不得被缩进快捷键截断。

## 5. 时间画布

### 5.1 表头与网格

- 两级表头：上层月/年，下层日/周标签。
- 月缩放隐藏非工作带，避免条纹噪声。
- 今天线绘制在 `todayX`。今天不在可见范围时不绘制；状态栏提供「回到今天」芯片与 `⌥⌘T`。
- 缩放：日 / 周 / 月 / 适合项目。拖动表头平移时间窗。本期不做横向滚动条。
- 自定义日宽（2–120 点/天）：全轴由**单一标量日宽**驱动，每天等宽、每周等宽，禁止按天/按周分叉宽度。
  刻度粒度由**实际生效日宽**推导（≥18 逐日 / ≥6 逐周 / 其余逐月），只决定刻度集合、不改变坐标等距性；
  表头下层标签上限 200，超出按 stride 抽稀（网格线不抽稀）。
  与前三档互斥：选预设回落 32/12/5 并清空自定义；开「适合项目」回落 fit 宽度并清空自定义。
  入口为工具栏标尺按钮的弹出面板（滑杆 + ± 步进 + 档位芯片 + 重置）、缩放菜单步进项与 `⌘+` / `⌘-` / `⌘0`。

### 5.2 任务条

- 任务：圆角条；群组：汇总条（两端帽形）；里程碑：菱形。
- 条内进度填充。
- 逾期红描边、重要路径紫描边、违例条尾三角。逾期与重要路径禁止双描边，逾期优先。
- 条标签可开关。默认位于条外右侧 6pt；右侧 <60pt 翻左；仍不足则隐藏。月缩放默认隐藏，悬停或选中显示浮层。
- 群组收合后，画布只绘制该群组汇总条并显示子项数；两栏行数一致。
- 无排期任务（依赖环、空群组等）不绘制条体；行内显示「未排期」灰字并注明原因；单击定位检查器对应字段。
- 项目开始日期缺失时，画布顶部显示信息条「未设置项目开始日期，已按最早任务开始日期推导」与「设置项目开始日期」入口。

### 5.3 依赖线

- FS / FF / SS / SF 四型直角折线，箭头指向后继。
- 依赖线绘制在非工作带之上、任务条之下。
- 悬停隔离相关线；命中区扩展到端点与线段周围 24×24 等效区域。
- 本期不提供点击编辑与拖拽建线。依赖创建只从检查器进入。

### 5.4 行对齐

计划模式使用单一纵向滚动容器加 `LazyVStack` 提供行骨架；时间画布使用一个与内容等高、宽度为画布视口的 `Canvas` 叠加层，统一绘制网格、非工作带、今天线、任务条与跨行依赖线；文本标签按可见行覆盖。禁止两个独立滚动视图用偏移同步。

## 6. 检查器

### 6.1 结构

- 常驻、可开关、可拖动宽度。顶部 40pt：面包屑、锁定、关闭。下一行标签页「检查器 | 违例 N」。
- 任务页：信息（类型只读、状态、优先级、标签、负责人）、排期（计划开始/结束只读、持续时间、投入、宽延只读、时限、ASAP/ALAP、截止日期与风险）、相关性（前置任务可编辑、后继只读）、资源、进度、备注、删除。
- 项目页（无选择）：标题、项目起止、方向、健康摘要、最近完成 5 条、规则检查建议、保存状态。
- 违例页：按 error / warning 分组，显示计数、类型、原因与相关任务；单击定位任务但不关闭页面。空态列出已检查的规则类别。
- 群组字段只读并标注聚合。

### 6.2 锁定与漂移

- 锁定为视图状态 `inspectorLocked`，不写入任务模型。
- 选择漂移时显示「选择已变更：<任务名> [切换]」。
- 锁定任务被删除时，保留最后一次锁定快照并显示「任务已删除 [关闭]」。
- 外部重载强制解锁并提示。

### 6.3 添加前置任务

- 320×400 弹出层：搜索任务、排除自己与后代、四型、延隔 −30…+30 天（步进 0.5）。
- 提交时执行环校验；成环被拒绝并说明原因。
- 删除依赖可撤销。

## 7. 健康度与违例

违例并入检查器标签页，取消底部 180pt 面板。

入口：

- 工具栏违例徽标。
- `⌥⌘V`。
- 整行或整条选择。

行内违例图标（18pt）与条尾三角（12pt）只作显示。

健康点由核心计算，界面只展示：

| 健康点 | 条件 |
|---|---|
| 红 | 存在 error 违例，或逾期未完成任务占比 > 20% |
| 橙 | 存在 warning 违例，或逾期 > 0，或缺少截止日期的任务占比 > 20% |
| 绿 | 其余 |

两个占比的分母均为未完成叶子任务；群组不计入。状态栏与项目页的计数必须同源。

`Violation` 当前没有受影响任务数组与修复动作。界面只提供「定位任务」，不提供「立即解决」。

## 8. AI 与协作可见性

只展示有数据支撑的事实，不放空壳面板。

- AI 过滤徽标：`AIFilterTranslator.translate` 解析出子句时显示；纯文本不显示。
- 命令面板：`⌘K`，与菜单栏同源。
- 复制任务深链：`kairo://task/<id>`。
- 最近完成：按 `completedAt` 取 5 条；5 分钟内的完成用 1 秒脉冲提示，不标注 AI。
- 外部更新条：应用前台每 2 秒比较 `.kairo` 的 mtime。
  - 本地无未保存修改：自动重载并提示「已载入外部更新 HH:mm」。
  - 有未保存修改：显示非模态条「项目已在磁盘上更新｜[重新载入] [保留本地]」。
  - 本期不提供「比较」入口。
- 本期不出现「AI 更新了 N 个任务」「AI 洞察」等无数据支撑的文案。

后续版本依赖模型扩展（`ChangeRecord`、`Violation.affectedTaskIDs/fixAction`）再提供每行 AI 来源徽标、协作时间线、违例自动修复与外部更新差异计数。本期只预留信息架构。

## 9. 定位、查找与空态

### 9.1 揭示目标

所有定位（违例、深链、查找、外部更新）统一为「揭示目标」：

1. 展开祖先。
2. 临时清除导致隐藏的筛选，并提示「已被筛选隐藏，已临时显示」。
3. 选中目标。
4. 不切换检查器页签。

查找只做高亮跳转，不改变筛选条件。

### 9.2 空态与异常态

| 场景 | 界面 |
|---|---|
| 空项目 | 「新建任务」与「通过 MCP 导入 WBS」两个入口 |
| 筛选无结果 | 说明当前筛选条件与清除入口 |
| 无违例 | 违例页列出已检查规则类别 |
| 缺项目开始日期 | 画布顶部信息条与设置入口；禁止 1970 年数据 |
| 保存失败 | 非模态错误条，保留未保存状态 |
| 窄窗 | 检查器收起；状态栏按优先级折叠 |
| 任务被删除 | 检查器回项目页并提示「任务已删除」 |

深色、高对比与减弱动态效果均必须有明确适配，不出现空白区。

## 10. 本期不做

## 11. 验收判据

1. 默认进入计划模式；同一任务第 N 行在大纲与画布的 y 坐标一致，日/周/月/适合均成立。
2. 今天线可见，或状态栏提供回到今天；状态栏显示剩余天数。
3. 所有依赖以直角折线绘制；悬停隔离；四型均可在检查器创建；成环被拒绝并说明原因。
4. 重要路径默认关闭；开启后条与线高亮，状态栏显示数量与图例；红色只用于错误与逾期。
5. 群组收合后画布显示汇总条与子项数，两栏行数一致；群组进度为加权聚合。
6. 进度、逾期、违例在行、条、状态栏三处同源；健康点规则与计数一致。
7. 无选择、筛选无结果、无违例、项目开始日期缺失、保存失败、窄窗、深色模式均有明确界面，不出现空白或 1970 年数据。
8. 视图文件不出现 `Project`、`TaskItem`、`KairoSession` 引用（`WorkspaceStore` 适配层除外）；所有变更经动作进入呈现层。
9. 删除群组有确认；单任务删除可撤销；依赖删除可撤销。
10. 1000 任务、50 条依赖时，选择/展开/缩放 ≤ 100ms；排期重算 ≤ 1s。

人工验收在 820 / 1120 / 1440 三档宽度与浅色、深色、高对比、减弱动态下逐条执行，并记录实际结果。
