## 2. 滑杆拖动与读数（对应 D-010）

- [ ] 拖动滑杆时**读数实时跟随**滑块位置变化（数值与滑块位置一致，不滞后）
- [ ] 拖动过程中**滑块不回跳**（节流提交的回声不与手势互相打断）
- [ ] 松手后读数与滑块位置**最终一致**，且状态栏日宽同步更新
- [ ] **节流窗口内关闭 popover**：先拖动滑杆，**在 100ms 内立刻关闭 popover**，读数与状态栏日宽应反映**最后一次拖动值**（不得停留在上一次提交值）→ 对应 **D-010** 的修复验证
- [ ] 拖动到两个端点：最左读数 **2 点/天**、最右读数 **120 点/天**，不出现负数、0 或超大值
- [ ] 拖动过程中界面**无明显卡顿**（1000 任务项目上观察，对应 D-014）
- [ ] 步进按钮 `更宽 1` / `更窄 1` 每次精确 ±1 点/天；连续点击时读数连续累加

## 3. 菜单档位与 ✓ 标记

- [ ] 预设档位（`日 32 点/天` / `周 12 点/天` / `月 5 点/天`）当前生效档位前缀显示 `✓ `，其余档位**无** ✓
- [ ] `适合项目` 生效时显示 `✓ 适合项目`
- [ ] **自定义日宽生效时，三个预设档位与「适合项目」都不打 ✓**（互斥规则）
- [ ] 点击 `更宽` / `更窄` 后，自定义生效，同样**无任何预设档位打 ✓**
- [ ] 点击 `重置宽度` 后回到**当前档位默认宽度**（日 32 / 周 12 / 月 5），并恢复对应档位的 ✓ 标记
- [ ] 菜单底部 `当前日宽：X 点/天` 与面板读数、状态栏读数**三处一致**

## 4. 快捷键（对应 D-015 / 设计稿 R-07）

- [ ] `⌘+` 加宽 1 点/天、`⌘-` 收窄 1 点/天、`⌘0` 重置为档位默认 —— 在**本机键盘布局**下均可用
- [ ] 若本机为**非美式布局**：`⌘+` 需要配合 Shift 才能触发 —— 记录实际行为；面板与菜单展示的「⌘+」文案是否与实际一致（不一致则登记新缺陷）
- [ ] **面板开启时**按 `⌘+`：面板读数与滑块位置应**更新**到新日宽（`onChange` 丢弃草稿、跟随生效值），不得卡在旧值
- [ ] 面板开启时按 `⌘0`：面板读数回到档位默认宽度
- [ ] `⌘K` 命令面板中能搜到「加宽每日 / 收窄每日 / 重置每日宽度」三条命令并可执行

## 5. 刻度粒度与标签（对应 D-007 回归的肉眼确认）

- [ ] 自定义日宽 **≥ 18 点/天** → 表头下层刻度为**逐日**
- [ ] 自定义日宽 **17.9 点/天** → 表头下层刻度切换为**逐周**（跨 18 阈值翻转正确）
- [ ] 自定义日宽 **6 点/天** → 逐周；**5.9 点/天** → **逐月**（跨 6 阈值翻转正确）
- [ ] 逐月档位下**非工作带（周末条纹）隐藏**，逐日/逐周档位下显示
- [ ] 各档位下**任务条标签不重叠**、不被裁切；标签密度观感可接受
- [ ] 任务条宽度与日宽**同步等比缩放**（每一天等宽、每一周等宽，不出现分段宽度不一致）
