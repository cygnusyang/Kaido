---
description: 汇总 Kaido 项目的计划、重要路径与违例
---

汇总当前 Kaido 项目的计划状态。

步骤：

1. 若当前会话尚未打开项目，先用 `project_open` 打开 `KAIDO_PROJECT` 指向的文件
   （未设置时询问用户）。
2. 依次调用：
   - `task_list`（空参数）取任务清单；
   - `schedule_compute` 取排期；
   - `schedule_critical_path` 取重要路径与宽延；
   - `violations_list` 取违例。
3. 用紧凑表格输出每个任务：ID 前缀、标题、状态、进度、持续天数、计划开始/结束、总宽延。
   群组行按层级缩进；里程碑持续为 0。
4. 违例逐条列出：违例码、涉及任务、原因。
5. 末尾给出三行汇总：任务数（完成/进行中/待办/阻塞）、重要路径任务数、违例数。

约束：

- 只读，不修改任何任务。
- 排期或违例工具报错时原样转述错误码与消息，不要用估算值替代。
